# Master Scheduler

Internal crew scheduling app for managing job assignments, team members, and time off. Access is restricted to company employees via Supabase authentication.

## Tech Stack

- React (Create React App)
- Supabase — auth, database, row-level security
- Deployed via Vercel or Netlify

## Project Structure

```
src/
  App.js                    Main component — state, routing, schedule/jobs/members views
  constants.js              Member colors, job categories, seed data
  supabaseClient.js         Supabase client initialization
  utils/
    dates.js                Date helper functions
    calendar.js             ICS export and invite token generation
  components/
    LoginScreen.js          Sign-in and invite code redemption
    SignupScreen.js         New account creation from invite
    MyAccountModal.js       Profile and password management
    UserManagementModal.js  Admin user list and role editing
    InviteModal.js          Admin invite code generation
    ModalWrap.js            Shared modal container
    QuickAssign.js          Quick job assignment picker
```

## Local Setup

1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your Supabase credentials
3. Install dependencies and start the dev server

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Environment Variables

```
REACT_APP_SUPABASE_URL=https://your-project.supabase.co
REACT_APP_SUPABASE_ANON_KEY=your-anon-key-here
```

These are required. The app will not authenticate without them. Never commit `.env` — it is listed in `.gitignore`.

## Supabase Setup

The following tables are required in your Supabase project:

**`profiles`** — one row per user, linked to `auth.users`

```sql
create table profiles (
  id uuid references auth.users on delete cascade primary key,
  name text not null,
  username text unique,
  email text unique,
  role text not null default 'viewer'
);
```

**`invites`** — invite codes generated by admins

```sql
create table invites (
  id bigint generated always as identity primary key,
  token text not null unique,
  email text,
  role text not null default 'viewer',
  used boolean not null default false,
  created_at timestamptz default now()
);
```

Row Level Security is enabled on both tables. A `get_my_role()` security-definer function is used to avoid recursive policy evaluation.

## User Roles

| Role   | Access                                                                      |
| ------ | --------------------------------------------------------------------------- |
| Admin  | Full access — create/edit jobs, assign crew, manage users, generate invites |
| Viewer | Read-only — can view the full schedule but cannot make changes              |

## Adding New Users

Admins generate a one-time invite code from within the app (Invite Users button). The code is sent to the employee, who enters it on the login screen to create their own account. Each code is single-use.

## Deployment

1. Push to a GitHub repository (ensure `.env` is not committed)
2. Connect the repo to [Vercel](https://vercel.com) or [Netlify](https://netlify.com)
3. Add `REACT_APP_SUPABASE_URL` and `REACT_APP_SUPABASE_ANON_KEY` in the platform's environment variable settings
4. Deploy — HTTPS is handled automatically

### `npm run eject`

**Note: this is a one-way operation. Once you `eject`, you can't go back!**

If you aren't satisfied with the build tool and configuration choices, you can `eject` at any time. This command will remove the single build dependency from your project.

Instead, it will copy all the configuration files and the transitive dependencies (webpack, Babel, ESLint, etc) right into your project so you have full control over them. All of the commands except `eject` will still work, but they will point to the copied scripts so you can tweak them. At this point you're on your own.

You don't have to ever use `eject`. The curated feature set is suitable for small and middle deployments, and you shouldn't feel obligated to use this feature. However we understand that this tool wouldn't be useful if you couldn't customize it when you are ready for it.
